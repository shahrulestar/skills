# Learn from what shipped

Use this when the user pastes the final version of a piece they sent and asks you to learn from it.

1. Ask the user to paste the version you drafted (if it is not in this chat) and the final version that went out.
2. Compare them. Note what they cut, added, reworded, or reverted.
3. Turn repeated patterns into rules, each with one quoted example from their real final. Do not make a rule from a single one-off change unless it is clearly a preference.
4. If the user keeps a voice profile, update it using `references/voice-profile-template.md` as the shape. Edit or remove rules the final contradicts. If they do not keep one, offer to draft one in the chat instead.
5. Reply in two lines saying what changed in the profile or which rules you would add.
