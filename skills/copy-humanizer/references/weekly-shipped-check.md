# On-demand shipped check

This skill cannot schedule reminders. Run this check only when the user asks for it, for example "check what I shipped this week."

1. Ask one short question: what copy went out this week, and what did you change before sending?
2. Accept a pasted final, a link the user shares, or a one-line answer.
3. When they hand you a final, follow `references/learn-from-what-shipped.md`, then reply with two lines on what changed.
4. If they skip the question or do not reply, drop it. Do not ask again in the same chat.

Never nag, never guess what shipped from a live page, and never send, post, or publish anything.
