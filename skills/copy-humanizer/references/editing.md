# Copy edit

1. If the user has a project voice profile, read it. If not, work from the piece itself.
2. Confirm the language: English, Malay, or Manglish. Keep the source language unless the user asked for another.
3. List every fact in the source: names, numbers, dates, claims, links, offers. None of them may change or disappear, and nothing new may be added.
4. Edit lightly. Cut filler, fix grammar and order, tighten sentences. Keep their word choices, rhythm, humour, and any Manglish or santai flavour unless it hurts clarity.
5. Run `references/anti-slop-pass.md` for that language.
6. Check the facts list against the result.
7. Reply with:
   - the edited version first, ready to copy and paste
   - a numbered list of what changed and why, one line each
   - if one reading of the source was a guess, say so in the list and offer to fix it
