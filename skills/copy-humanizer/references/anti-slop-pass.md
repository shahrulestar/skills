# Anti-slop pass

Run the section for the chosen language, then the shared checks.

## English

Cut or rewrite:
- openers like "I hope this finds you well" or "In today's fast-paced world"
- filler intensifiers: truly, incredibly, seamlessly, robust, leverage, delve, elevate, unlock, game-changer
- hedge stacks ("it might perhaps be worth considering")
- rule-of-three lists that exist only for rhythm
- "It's not X, it's Y" contrasts
- em-dash chains: use commas or periods
- headers, bold, and bullets in a message that should just be prose
- closing summaries that repeat the body
- fake enthusiasm and exclamation marks the user would not use

## Malay

Cut or rewrite:
- openers like "Dalam era yang serba pantas," "Tidak dapat dinafikan," or "Sebagai pengenalan"
- filler like "secara keseluruhannya," "dari segi praktikalnya," "pada hemat saya" stacked in one paragraph
- inflated verbs: memperkasa, mengoptimumkan, merevolusikan, memacu, meneroka (when it is decoration)
- "mari kita terokai" and similar calls to explore unless the channel is a presentation
- stacked "yang" clauses: "produk yang yang direka yang..."
- literal calques from English: "mengambil masa untuk menghargai" for "take time to appreciate," "dalam hal ini" repeated in every sentence
- fake enthusiasm: "Wah!!!" or "Best gila!!!" when the user would not write that
- closing summaries that repeat the body

## Manglish

Cut or rewrite:
- a particle (lah, lor, meh, kan) on every line
- corporate English with a "lah" glued on the end
- textbook English that "corrects" Manglish when the user asked for Manglish
- forced slang that the user never used
- bullet dumps in a chat message

Keep the particles and code-switch the voice really uses.

## Then check

- every sentence earns its place
- it sounds like the user said it out loud
- words from the user's avoid list are gone
- spelling matches the chosen language and the user's preference (English default: Malaysian English with British spelling)
- santai or baku register matches the channel
- no fact was added, dropped, or changed
